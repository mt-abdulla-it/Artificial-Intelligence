## 📂 Included Projects

### 1. 📈 Simple Linear Regression
- Exploratory data analysis (EDA) and univariate feature correlation.
- Model training, ordinary least squares (OLS) regression line fitting, and error residual plotting.
- Evaluation using Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² score metrics.

### 2. 📊 Multiple Linear Regression
- Multivariate correlation matrices and multicollinearity analysis (Variance Inflation Factor).
- Feature scaling, train-test splitting, and hyperparameter tuning.
- Comparative evaluation of multivariate predictive performance against ground truth test sets.
